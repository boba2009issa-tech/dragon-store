# Dragon Premium Watches — V4

Static luxury storefront using HTML, CSS, Tailwind CDN, Vanilla JS and JSON.

## V4 fixes
- Hardened responsive header: no horizontal overflow, better mobile spacing, compact brand mark, clean desktop navigation.
- Replaced the broken `ig.me` destination with the public Dragon Instagram profile: https://www.instagram.com/drago__n1_/
- Checkout copies the full order message (name, phone, governorate, address, notes, products, quantities and total) and opens the Dragon Instagram profile in a new tab.
- Instagram does not provide a public static URL that can silently send a prefilled arbitrary DM. The user must tap Message, paste the copied order, and send it.
